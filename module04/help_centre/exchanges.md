# Size exchanges

## Which items can be exchanged
Footwear and clothing can be exchanged for a different size of the same product within 10 days of delivery, if that size is in stock. Other categories cannot be exchanged - return the item and place a new order instead.

## How exchanges work
Choose Exchange in My Orders and pick the new size. The courier delivers the new size and picks up the old one in the same visit, so you never pay twice. Each item can be exchanged once.

## If the size is out of stock
If the size you want is out of stock, return the item for a refund instead and order again when it is back.
