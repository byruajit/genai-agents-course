# Coupons and offers

## Using coupons
Apply one coupon per order at checkout. Coupons cannot be combined with each other, and do not apply to gift cards.

## Coupon not working
A coupon may fail if the order is below its minimum value, if it has expired, if it was already used, or if the items in the cart are excluded. The checkout page shows the reason.

## First order offer
New customers get 10% off their first order, up to Rs 200, with the code WELCOME10.
